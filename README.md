# Simple LLM Form Filler

This is a simple tool to demonstrate LLM-based automation possibilities by adding a context menu entry to automatically generate content for forms.

The tool queries the label of the form and calls an LLM (local or remote, ollama or openrouter) to provide answers, using an optional text file as additional context. Disclaimer: the tool is vibe-coded (although some care was taken to improve the readability of the code.
